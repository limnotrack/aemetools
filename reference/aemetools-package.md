# aemetools: Tools to expand the Aquatic Ecosystem Model Ensemble Package

Calibrate the AEME model ensemble, download ERA5-Land data for any point
in New Zealand, and run simple hydrological models to generate inflow
inputs for the AEME model ensemble.
