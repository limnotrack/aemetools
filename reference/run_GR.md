# Run GR model

Run GR model

## Usage

``` r
run_GR(
  inputs,
  param,
  warmup = NULL,
  run_index,
  IniStates = NULL,
  IniResLevels = NULL
)
```

## Arguments

- inputs:

  list; of inputs generated by [`make_GR_inputs()`](make_GR_inputs.md).

- param:

  vector; of parameters. Usually generated from
  [`calib_GR()`](calib_GR.md).

- warmup:

  vector; index of `inputs$data` to be used as a warmup period for the
  model.

- run_index:

  vector; index of `inputs$data` to be used for running the GR model.

- IniStates:

  (optional) \[numeric\] object of class `IniStates` \[mm and °C\], see
  [`CreateIniStates`](https://rdrr.io/pkg/airGR/man/CreateIniStates.html)
  for details

- IniResLevels:

  (optional) \[numeric\] vector of initial fillings for the GR stores (4
  values; use NA when not relevant for a given model) \[- and/or mm\].
  See details

## Value

list of GR model output.
