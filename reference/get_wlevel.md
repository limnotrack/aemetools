# Get modelled water level

Get modelled water level

## Usage

``` r
get_wlevel(lake_dir, model, nlev, return_df = FALSE)
```

## Arguments

- lake_dir:

  lake directory

- model:

  string; model name.

- nlev:

  numeric; number of levels to extract.

- return_df:

  logical; return dataframe of water level. Default is FALSE.

## Value

dataframe of water level.
