# Write calibration/sensitivity analysis .csv files to database

Write calibration/sensitivity analysis .csv files to database

## Usage

``` r
write_csv_to_db(file_dir, file_name = "results.db")
```

## Arguments

- file_dir:

  The directory where the .csv file is located.

- file_name:

  The name of the database file to write to. Default is "results.db".

## Value

file path to the database.
