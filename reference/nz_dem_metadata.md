# sf object of Digital Elevation Model (DEM) metadata for New Zealand.

This can be used to query DEM coverage and metadata for New Zealand.

## Usage

``` r
nz_dem_metadata
```

## Format

### `nz_dem_metadata`

A sf data frame with 230 rows and 8 columns:

- layer_id:

  Layer ID of the DEM

- title:

  Title of the DEM

- abstract:

  Abstract of the DEM

- region:

  Region of the DEM

- res:

  Resolution of the DEM. Units are in denoted in the units column.

- units:

  Units of the resolution DEM

- year:

  Year of the DEM

- geometry:

  Geometry of the DEM
